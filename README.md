# VELUM

Custom **3D** top-down action RPG in the browser — Diablo-style click-to-move, stylized Three.js characters, real-time combat.

## Play

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Controls

| Input | Action |
| --- | --- |
| Hold / click left mouse | Move to that point |
| Click / hold on enemy | Chase and auto-attack |
| Right mouse / Shift / K | Dodge |
| E / Space | Talk to Elder Voss |

## Goal

Collect **3 Velum Crystals**, then defeat the **Ash Golem** in the southeast.
